# 真实设备测试清单

游戏地址：<https://casperfrome.github.io/texas-holdem/>

两个人各拿一台设备，按下面的顺序测。每一项记下"正常"或"有问题 + 现象"，最后把结果发给我。遇到问题时，截图最有用。

## 要覆盖的设备

尽量每种都至少打几手：

| 设备 | 浏览器 | 网络 |
|---|---|---|
| iPhone | Safari，以及装到主屏幕后的图标 | WiFi 和手机流量 |
| Android 手机 | Chrome，以及安装后的图标 | WiFi 和手机流量 |
| Mac | Chrome 或 Safari | WiFi |
| Windows | Chrome 或 Edge | 任意 |

## 一、建房和加入

1. 房主打开游戏地址，点"创建房间（我当房主）"。
2. 房主点底部"邀请朋友"，用微信等把链接发给朋友。
3. 朋友点开链接。
   - [ ] 朋友直接进入牌桌，能看到自己的两张牌
   - [ ] 房主顶部"朋友还没加入"的提示消失
   - [ ] 地址栏里看不到 `#join=...` 这段（打开后应自动去掉）

## 二、正常打牌

4. 打 5 手以上：过牌、跟注、加注、全下、弃牌都试一下。
   - [ ] 一方操作后，另一方大约 1 秒内看到
   - [ ] 加注金额的快捷按钮（½ 池、1 池等）和滑杆好用
   - [ ] 摊牌时双方的牌型和输赢判断正确
   - [ ] 文字、牌面在手机上不挤、不被挡住（尤其是 iPhone 的刘海和底部横条）
5. 一直打到一方输光。
   - [ ] 显示谁赢了这一局，"再来一局"可以开始新的一局，比分正确累计

## 三、断线和恢复

6. 朋友在轮到自己时，把浏览器切到后台（比如去微信），过 30 秒再切回来。
   - [ ] 回来后几秒内恢复，画面是最新的
7. 朋友操作后，立刻把手机切到飞行模式 10 秒，再关掉飞行模式。
   - [ ] 显示"发送中…"，恢复网络后操作被执行，没有重复执行
8. 房主关掉页面，过一会儿再打开游戏地址。
   - [ ] 朋友那边显示"房主不在线，牌局暂停"
   - [ ] 房主回来后接着原来那手牌打，筹码没变
9. 手机锁屏 1 分钟再解锁。
   - [ ] 能自动恢复（联机时游戏会尽量保持屏幕常亮）

## 四、换设备当房主

10. 房主在当前设备点"换设备"，复制房主链接，在另一台设备打开。
    - [ ] 新设备接着同一手牌，筹码和牌面都对
    - [ ] 旧设备显示"已在其他设备打开"
11. 在旧设备点"改回在这台设备上当房主"。
    - [ ] 进度又回到旧设备，新设备显示"已在其他设备打开"

## 五、装到主屏幕 / 桌面

12. 在牌桌底部点"安装"，按提示操作：
    - iPhone：Safari 分享按钮 →"添加到主屏幕"
    - Android：Chrome 菜单 →"安装应用"
    - Windows / Mac 的 Chrome、Edge：地址栏右侧的安装图标
13. 从主屏幕 / 桌面图标打开。
    - [ ] 图标是绿色背景的黑桃 A 和红桃牌
    - [ ] 全屏显示，没有浏览器地址栏
    - [ ] iPhone：第一次打开会回到首页，在"已经有链接？"里粘贴链接（"安装"面板里可以复制）后进入房间，进度不丢
    - [ ] 之后再从图标打开，直接进入房间

## 发给我的内容

- 每项的结果（正常 / 有问题 + 现象）
- 有问题时的截图，以及当时用的设备、浏览器、网络
- 打起来哪里不顺手、想加什么功能
