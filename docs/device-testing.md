# 真实设备测试清单

游戏地址：<https://156.225.76.31:1108/>

两个人各拿一台设备，按下面的顺序测。每一项记下"正常"或"有问题 + 现象"，最后把结果发给我。遇到问题时，截图最有用。

## 要覆盖的设备

尽量每种都至少打几手：

| 设备 | 浏览器 | 网络 |
|---|---|---|
| iPhone | Safari，以及装到主屏幕后的图标 | WiFi 和手机流量 |
| Android 手机 | Chrome，以及安装后的图标 | WiFi 和手机流量 |
| Mac | Chrome 或 Safari | WiFi |
| Windows | Chrome 或 Edge | 任意 |

## 一、账号、建房和加入

1. 两个人各自打开游戏地址，各注册一个账号（用户名 + 随便一个密码）。
   - [ ] 注册后直接进入大厅，右上角显示自己的名字和"胜 0 · 负 0"
   - [ ] 用已经注册过的用户名再注册，提示"已经被注册"；密码输错提示"用户名或密码不对"
2. 房主点"创建房间"，设一个密码，观战席选"2 人"。
3. 房主点底部"邀请"，用微信等把链接发给朋友，密码另外告诉他。
4. 朋友点开链接，登录后应该直接弹出这个房间。
   - [ ] 输错密码提示"密码不对"；输对后点"坐下打牌"进入牌桌，能看到自己的两张牌
   - [ ] 房主顶部"还没有对手"的提示消失，牌局自动开始
   - [ ] 朋友回大厅时（点"离开"之前先别点），房间列表里能看到这个房间，带锁的图标
5. 页面应显示服务器连接状态；新服账号与旧版独立。测试错误密码、退出登录及换设备登录。

## 二、正常打牌

6. 打 5 手以上：过牌、跟注、加注、全下、弃牌都试一下。
   - [ ] 一方操作后，另一方大约 1 秒内看到
   - [ ] 加注金额的快捷按钮（最小、½池、¾池、1池、全下）按钮上写着金额，点了之后高亮、下方金额跟着变；滑杆和数字框好用
   - [ ] 轮到谁，谁的座位下方有 15 秒倒计时条，两边显示的秒数差不多；最后 5 秒变红，轮到自己时手机震动一下
   - [ ] 故意不操作：15 秒后能过牌就自动过牌，否则自动弃牌，记录里显示"（超时自动）"
   - [ ] 对手思考时点"催一催"：对方弹出"××催你快点！"、有提示音和震动；同一轮再点按钮是灰的
   - [ ] 摊牌时双方的牌型和输赢判断正确
   - [ ] 文字、牌面在手机上不挤、不被挡住（尤其是 iPhone 的刘海和底部横条）
7. 一直打到一方输光。
   - [ ] 显示谁赢了这一局，"再来一局"可以开始新的一局，比分正确累计

## 三、断线和恢复

8. 朋友在轮到自己时，把浏览器切到后台（比如去微信），过 10 秒再切回来。
   - [ ] 回来后几秒内恢复，画面是最新的
   - [ ] 再试一次离开超过 15 秒：回来时这一步已经被自动过牌或弃牌
9. 朋友操作后，立刻把手机切到飞行模式 10 秒，再关掉飞行模式。
   - [ ] 显示"发送中…"，恢复网络后操作被执行，没有重复执行
10. 房主关掉页面，过一会儿再打开游戏地址。
   - [ ] 断线者保留座位 60 秒，服务器继续计时并自动过牌或弃牌；超过 60 秒后腾位，本局不计战绩
   - [ ] 房主回来后直接回到房间，接着原来那手牌打，筹码没变
11. 手机锁屏 1 分钟再解锁。
   - [ ] 能自动恢复（联机时游戏会尽量保持屏幕常亮）

## 四、观战

12. 找第三个人（或者用第三台设备注册第三个账号），从邀请链接进房，选"观战"。
    - [ ] 观众看到双方都是牌背，公共牌、下注、倒计时都正常；摊牌时才看到双方的牌
    - [ ] 观众没有操作按钮，也不能催
    - [ ] 牌桌下方显示"观战 1/2：××"
13. 玩家点底部"站起"。
    - [ ] 玩家变成观众，房主桌上显示"等待对手坐下"
    - [ ] 观众这边出现"坐下打牌"按钮，点了之后开始新的一局

## 五、换设备当房主

14. 房主在另一台设备上登录同一个账号，在"我的房间"里点"进入"。
    - [ ] 新设备接着同一手牌，筹码和牌面都对，朋友不用做任何事
    - [ ] 旧设备显示"已在其他设备打开"
15. 在旧设备点"改回在这台设备上玩"。
    - [ ] 进度又回到旧设备，新设备显示"已在其他设备打开"

## 六、装到主屏幕 / 桌面

16. 在牌桌底部点"安装"，按提示操作：
    - iPhone：Safari 分享按钮 →"添加到主屏幕"
    - Android：Chrome 菜单 →"安装应用"
    - Windows / Mac 的 Chrome、Edge：地址栏右侧的安装图标
17. 从主屏幕 / 桌面图标打开。
    - [ ] 图标是绿色背景的黑桃 A 和红桃牌
    - [ ] 全屏显示，没有浏览器地址栏
    - [ ] iPhone：第一次打开需要再登录一次，之后进入房间，进度不丢
    - [ ] 之后再从图标打开，直接回到上次的房间
